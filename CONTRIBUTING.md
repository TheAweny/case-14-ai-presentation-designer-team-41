# Как участвовать

Спасибо за интерес к проекту. Ниже — минимум, которого достаточно, чтобы ваш патч прошёл ревью.

## Окружение

```bash
corepack enable
yarn install
uv sync
```

Нужны Node 22.13+ и Python 3.12 (uv поставит его сам). Пакетный менеджер для TypeScript —
только yarn, для Python — только uv.

## Перед пушем

```bash
yarn lint && yarn typecheck && yarn test
yarn lint:py && yarn typecheck:py && yarn test:py
yarn boundaries:py
yarn codegen && git diff --exit-code
```

Хуки `lefthook` линтят только изменённые файлы, полный набор гоняет CI.

## Правила, о которых спрашивают чаще всего

- **Границы слоёв.** В Python-движке нет ни одного вызова модели, в TypeScript нет работы
  с `.pptx`. Слои движка не импортируют друг друга. Правила закреплены в `import-linter` и
  `@nx/enforce-module-boundaries`; отключать их, чтобы «прошло», нельзя.
- **Никакой заточки под шаблон.** Ни условий вида «если шаблон такой-то», ни зашитых названий
  макетов, цветов, шрифтов и координат. Всё, что зависит от шаблона, берётся из профиля шаблона.
- **Контракты.** Источник правды — Zod-схемы в `packages/contracts`. Pydantic-модели движка
  генерируются; править сгенерированные файлы руками нельзя. После правки схем запустите
  `yarn codegen` и закоммитьте результат одним коммитом со схемами.
- **Промпты.** Инструкции агентов лежат в `registry/agents/<id>/instructions.md`, в коде
  промптов быть не должно. Поменяли смысл инструкции — поднимите версию в `agent.yaml` по semver.
- **Тесты.** Каждая новая проверка аудита приходит с двумя тестами: слайд, который её нарушает,
  и слайд, который ей соответствует. Тесты пайплайна работают с фейковым провайдером моделей,
  без GPU и без сети.
- **Генерируемые файлы.** `docs/AUDIT.md` и `docs/LICENSES.md` собираются утилитами из `tools`,
  руками их не правим.

## Лицензии зависимостей

Решение открытое, поэтому новая зависимость допустима только под MIT, Apache-2.0, BSD, ISC или
MPL. GPL и AGPL не подходят: заказчик берёт решение в пилот и внедрение. Проверка:

```bash
yarn licenses
```

Задача пересобирает `docs/LICENSES.md` и падает, если в дереве появился копилефт.

Отдельно про шрифты: в образы кладём только свободные шрифты, а шрифты пользовательского
шаблона достаём из самого файла во время работы. Коммитить чужие корпоративные шрифты нельзя.

## Git

Короткие ветки от `main`, коммиты в стиле conventional commits, значимые архитектурные решения —
абзацем в `docs/DECISIONS.md`. Датасет организаторов, содержимое `runs/` и `.env` в репозиторий
не попадают.

## Лицензия вклада

Отправляя патч, вы соглашаетесь, что он распространяется на условиях Apache License 2.0 —
той же лицензии, под которой распространяется проект.
