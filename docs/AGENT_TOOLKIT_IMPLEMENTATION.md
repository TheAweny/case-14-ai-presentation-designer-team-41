# Реализация инструментария агентов

Дата начала: 2026-10-18. План продолжает [каталог инструментов](AGENT_TOOLS_ROADMAP.md).
Наличие пункта в таблице не означает готовность: инструмент принимается только после
подключения к реальному чату, проверки прав доступа и независимого прогона.

## Принятые ограничения

- Пользователь разрешил самостоятельный поиск в интернете; новые платные сервисы не нужны.
- Поиск работает через собственный SearXNG. Настройка URL остаётся на сервере, ключ не нужен.
  [Официальный HTTP API](https://docs.searxng.org/dev/search_api.html) поддерживает JSON;
  его необходимо разрешить в настройках экземпляра.
- Материалы пользователя, результаты поиска, прочитанные страницы и допущения имеют разное
  происхождение. Цитата подтверждает содержимое источника, но не истинность утверждения.
- Поиск и исследование выполняются при подготовке. Сборка не ищет заново для каждого
  слайда или варианта. Общий план и факты переиспользуются.
- Инструмент возвращает небольшой структурированный ответ с продолжением, если данные
  не помещаются. Пустая страница результатов не доказывает отсутствие факта во всём файле.
- Сохранённая колода и несохранённый черновик редактора различаются явно. Проверка старого
  файла не подтверждает новую правку. Редактирование проходит через существующие ревизии
  и механизмы применения в редакторе.

## Распределение Grok

Первая группа получает отдельные файлы: поиск по файлам, профиль макета, калькулятор,
загрузка веб-источника, поисковый адаптер с конфигурацией и проверка покрытия.
Интеграция в общий `chat-tools.ts`, реестр и интерфейс выполняется следующими заданиями,
когда имена функций и форматы ответов уже зафиксированы. Общие файлы принадлежат одному
исполнителю на время задания.

Координатор занимается архитектурой, последовательностью, независимыми тестовыми
сценариями, чтением диффов и приёмкой. Дефекты возвращаются исполнителям с воспроизведением.
Работа коммитится отдельными законченными частями вместе с относящимися к ним тестами.

## Обязательные сквозные сценарии

1. В длинном русском документе бюджет находится в конце, результат сохраняет точную цитату
   и абсолютные позиции; файл другого чата недоступен.
2. Расчёт уменьшения 18 до 11 минут воспроизводим; срок окупаемости не получается из минут
   без денежного эффекта.
3. Веб-поиск возвращает ссылки и даты без выдуманных подтверждений. Страница с командами
   внутри текста остаётся данными, перенаправление во внутреннюю сеть отклоняется.
4. Агент читает таблицу с пустыми ячейками и единицами, извлекает документ и может использовать
   подготовленный материал в сборке, а не только пересказать его в чате.
5. Утверждение с отрицанием и условием не проходит coverage после их потери; заметки
   докладчика не заменяют видимый тезис.
6. Проверка переполнения не меняет текст. Проверка статуса не повторяет сборку. Старое
   превью не объявляется проверкой несохранённого слайда.

## Отчёт о завершении

По каждому этапу в этом файле фиксируются доступные возможности, проверки и ограничения.
Заготовки и экспериментальные модули не перечисляются как работающие инструменты.

### Принятые модули и границы проверки

- Поиск по текстовым вложениям, калькулятор и подробный профиль макета подключены к dispatcher.
  Роли карточек берутся из индекса с совпадающим хешем шаблона; старый индекс возвращает unknown.
- Веб-поиск, чтение страниц, ограниченный исследователь и поиск изображений используют внутренний
  SearXNG без платных ключей. Внешние страницы проверяются по DNS и каждому перенаправлению;
  соединение чтения закреплено за проверенным IP. Сниппеты не становятся доказательствами.
- DOCX/PDF/XLSX готовятся Python-движком перед запуском таймера генерации. XLSX читается по всем
  листам; ячейки сохраняют адреса. TXT/MD/CSV/TSV сохраняют исходный текст. Неполный разбор,
  PDF без текстового слоя и превышение бюджета завершаются явной ошибкой; OCR пока отсутствует.
- `extract_material` отдаёт страницы подготовленного текста с координатами prepared-text-utf16,
  а не смещения в бинарном файле. `read_table` сохраняет пустые ячейки, формулы и кэшированные
  значения. Восемь обращений к движку за ход разделяются между этими инструментами.
- Источники сохраняются между ходами чата и передаются сборке отдельно от требований человека.
  `inspect_sources` показывает короткие выдержки и происхождение. Сводки модели и поисковые
  сниппеты в фактический бриф не попадают. Конфликты и допущения обозначаются not-assessed:
  автоматическая проверка истинности не реализована.
- Превью связано с хешем сохранённого плана и байтами PNG из манифеста. Проверки сохранённого
  слайда не подтверждают несохранённый черновик редактора и не заявляют визуальную оценку модели.
  Покрытие ищет точные обязательные фразы; пересказ требует ручной проверки.
