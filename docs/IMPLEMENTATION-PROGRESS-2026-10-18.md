## Результат Bugbot на da6706c

Полный CI PR #6 прошёл. Bugbot оставил три замечания:

1. [Таймаут не отменяет визуальные запросы](https://github.com/TheAweny/case-14-ai-presentation-designer-team-41/pull/6#discussion_r4307808638).
   Подтверждено чтением: runner прекращает ожидание, provider продолжает работать с общим
   сигналом сборки. Нужна отмена отдельной проверки и запрет поздней записи артефактов.
   Упоминание unhandled rejection в отчёте бота не считается доказанным самим Promise.race.
2. [Визуальные находки не входят в итоговую проверку](https://github.com/TheAweny/case-14-ai-presentation-designer-team-41/pull/6#discussion_r4307808645).
   Подтверждено: final-review.json формируется до визуального прохода. Его счётчики и статус
   используются при рекомендации варианта.
3. [Параллелизм после vision 429 не восстанавливается](https://github.com/TheAweny/case-14-ai-presentation-designer-team-41/pull/6#discussion_r4307808649).
   Подтверждено: VisionProvider замедляет общий лимитер, но не регистрирует успех.

## Дополнительные независимые проверки

- Прямой вызов `reviewVariantVisually` с fixture DeckImportResponse и пустым previews:
  один вызов модели, одна review, ноль failures. Проверка без картинки ошибочно считается
  визуальной. Probe запускался из stdin через yarn tsx, production code не менялся.
- `engine.parser.slides.read_deck` задаёт imported slide variant равным balanced.
  Визуальные находки dense/airy должны получать фактический вариант сборки.
- `GenerationService.start` начинает отсчёт после чтения contentIds. Подготовка внутри
  принятого запроса должна входить в deadline, а не исчезать из замера.
- `readPreparedMaterial` уже принимает AbortSignal; текущий start его не передавал.
- Неназначенные planner/critic возвращают null из resolveRole и используют выбранный writer.
  Это поведение сохранится; оснований исправлять предполагаемый routing bug нет.
