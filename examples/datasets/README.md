# Примеры датасетов

Наборы данных для второй ступени: все виды данных из задания, в каждом формате, который читает
сервис. Каждый формат лежит в двух вариантах. Первый аккуратный. Второй написан так, как
настоящие выгрузки обычно ломаются. Цифры синтетические и не из датасета организаторов.

Файлы собирает `generate.py` с фиксированным seed: повторная сборка даёт те же байты.

```bash
uv run python examples/datasets/generate.py
```

Тесты движка читают файлы как есть (`engine/tests/test_dataset_corpus.py`). Prettier их не
трогает: сломанные файлы сломаны специально.

## Что есть

| Вид данных из задания          | Аккуратный файл             | Сломанный файл                     |
| ------------------------------ | --------------------------- | ---------------------------------- |
| Временной ряд                  | `csv/revenue-monthly.csv`   | `csv/revenue-monthly-1c-export.csv` |
| Сравнение категорий            | `xlsx/regions-sales.xlsx`   | `xlsx/regions-report-messy.xlsx`   |
| Доли                           | `json/sales-channels.json`  | `json/sales-channels-bi-export.json` |
| Распределение                  | `tsv/order-checks.tsv`      | `tsv/order-checks-dirty.tsv`       |
| Справочная таблица от 200 строк | `csv/product-catalog.csv`  | лист «Справочник» в `regions-report-messy.xlsx` |
| Данные с пропусками            | `md/site-traffic-gaps.md`   | `md/site-traffic-wiki.md`          |
| Текст со встроенной таблицей   | `txt/quarter-report.txt`    | `txt/quarter-report-pasted.txt`    |

## Чем сломаны сломанные

- `revenue-monthly-1c-export.csv` — выгрузка из 1С. Кодировка Windows-1251, разделитель `;`,
  десятичная запятая, запятая в названии столбца («Выручка, тыс. руб.»), даты через точку,
  тысячи через неразрывный пробел. Над таблицей строка-заголовок, внизу строка «Итого», переводы
  строк CRLF и пустые строки в конце.
- `regions-report-messy.xlsx` — книга аналитика. Объединённый заголовок над таблицей и пустая
  строка под ним. Столбец процентов, число, записанное текстом. Формула с сохранённым
  результатом, формула без результата и ошибка `#DIV/0!`. Столбец дат, скрытый служебный лист,
  пустой лист и справочник на 300 строк.
- `sales-channels-bi-export.json` — выгрузка BI. BOM в начале, формат «столбцы + строки».
  Проценты строками с пробелом и без («46%», «31 %»), десятичная запятая и точка в одном
  столбце, `null`, объект и список в ячейках. Строка-запись с другим порядком ключей. Доли из-за
  округления дают 101 %.
- `order-checks-dirty.tsv` — чеки, которые вели вручную. Знак рубля до и после числа, «руб.»,
  возвраты в скобках, опечатка 9 999 999. Пропуски записаны по-разному: пусто, «н/д», «—». Два
  столбца с одинаковым названием, перенос строки внутри ячейки в кавычках, строка с лишним полем.
- `site-traffic-wiki.md` — таблица из вики. Жирный шрифт и код в ячейках, даты через точку.
  Пропуски записаны как «—», «н/д» и «n/a». Экранированная `\|` внутри ячейки, ссылка и эмодзи.
- `quarter-report-pasted.txt` — сообщение из мессенджера. Таблица без внешних `|` с
  выравниванием `:---`, блок, вставленный из Excel через табуляции. Строки с `|`, которые
  таблицей не являются. Пропуск «н/д».

## Файлы, которые не таблица

В `invalid/` лежат файлы, на которые сервис должен ответить понятной причиной, а не пустой
таблицей:

- обрезанный JSON;
- картинка с расширением `.csv`;
- пустой файл;
- старый `.xls`;
- Markdown без таблицы.
