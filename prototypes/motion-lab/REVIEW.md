# Проверка анимаций

Проверка относится только к этому демо.

| Исходное поведение                               | Адаптация                                                          | Причина                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| Подсветка меню анимирует top и height            | Смещение через transform, высота строки без перехода               | Убрана анимация раскладки при навигации                                     |
| Положение effort менялось мгновенно              | Значение меняется сразу, визуальный переход 220 мс через transform | Плавность по запросу пользователя; переход прерывается при повторном выборе |
| Thought Line завершается за 350 мс               | 240 мс                                                             | Общий ритм состояний                                                        |
| Программный фокус закрывал меню при первом клике | Меню закрывается по выбору, Escape, вводу и клику вне              | Предсказуемое открытие                                                      |
| Только системная настройка уменьшенного движения | Система и общий контекст переключателя демо                        | Canvas очищается в обоих режимах                                            |

Сохранены исходные эффекты: морфинг стрелки, частицы, решётка, дыхание, shimmer,
сворачивание этапов. Фокус виден, hover ограничен точным указателем. Длительности
интерфейсных переходов 160–240 мс. Canvas ограничен 30 частицами, очищается при
размонтировании и смене режима. Ключевой код: `components/PromptBar.tsx`,
`components/ThoughtLine.tsx`, `motion-preference.ts:5`.

Сворачивание этапов сохраняет CSS grid оригинала: небольшой блок из трёх строк,
без измерения размеров на каждом кадре. В reduced motion сворачивание мгновенное.

Решение: **Approve** для демо. При интеграции проверить эффекты с реальным потоком
ответов и рендером слайдов.
