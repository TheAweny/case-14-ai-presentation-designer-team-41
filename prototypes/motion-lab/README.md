# Components demo

Изолированное демо трёх компонентов перед интеграцией в основной фронтенд.
Только тёмная нейтральная палитра, без отдельного бренда и макетов продукта.
Код `apps/web` не подключается и не изменяется.

Запуск из корня: `yarn nx run motion-lab:serve`. Адрес: http://127.0.0.1:4314.
Проверки: `yarn nx run-many -p motion-lab -t typecheck lint build`.
Браузерный smoke при запущенном стенде: `yarn nx run motion-lab:smoke`.
Для установленного Chrome: `$env:MOTION_LAB_BROWSER = 'chrome'` в PowerShell.

- Prompt Bar: ширина для чата и панели, максимальный effort с частицами. Отправка показывает
  последовательность Thought Line → Lattice Loader → завершение. Остановка отменяет таймеры.
- Lattice Loader: размеры 3 × 3 и 4 × 4, несколько паттернов, работа, завершение, ошибка.
- Thought Line: этапы со сворачиванием, одна строка, точка. Завершённые этапы можно раскрыть.

Режимы соответствуют контракту `ChatMode`: «Чат» отвечает после размышления,
«План» показывает структуру и ждёт одобрения, «Авто» начинает сборку сразу после размышления.
По умолчанию выбран «План», как в приложении. Размышление — общая политика всех режимов,
не отдельный переключатель. Effort — независимая настройка по возможностям модели.
В демо всегда передаётся `reasoning: true`, а поле `effort` отсутствует, если поддержка
не подтверждена. Это локальный тип запроса стенда, не изменение API приложения.

Генерация симулируется за семь секунд. Скрепка открывает выбор файлов в один клик.
Можно отправить только файлы, убрать отдельные вложения, сменить модель или режим без потери
выбранных файлов. После отправки их имена остаются у сообщения.
Файлы остаются в браузере, используются только имена.
В меню конкретные модели: `Qwen3.5 27B` (по умолчанию) и `GPT OSS 20B`.
Обе поддерживают размышление; GPT OSS позволяет выбрать низкое, среднее или высокое усилие.
У Qwen регулятор effort скрыт: переключение thinking не означает поддержку `reasoning_effort`.
Вариант Max effort открывается на GPT OSS с высоким усилием. Выбранный id входит в запрос
симуляции. Это примеры для локального прототипа, а не проверенный список подключённых серверов.
Модели и регулятор effort в этом демо не подключены к API генерации.

Режим и рисунок загрузчика используют общий `ChoicePicker`: однострочные пункты без описаний,
отметка текущего выбора, стрелки, Home/End, Escape и Tab. При открытии мышью фокус не
переносится в список; с клавиатуры он попадает на выбранный пункт.
Модель и усилие объединены в одну кнопку справа: имя модели, приглушённое усилие и стрелка.
В меню сразу видны модели и нейтральный компактный ползунок. У моделей без регулировки усилия
остаётся выбор модели и отметка включённого размышления. Меню модели и режима взаимно
исключают друг друга и не сбрасывают текст и вложения. Если сверху не хватает места,
меню открывается вниз.

## Происхождение

Компоненты получены из официального реестра React Bits 2026-10-16:

- https://reactbits.dev/r/PromptBar-TS-CSS.json
- https://reactbits.dev/r/LatticeLoader-TS-CSS.json
- https://reactbits.dev/r/ThoughtLine-TS-CSS.json

Автор — David Haz. MIT + Commons Clause сохранена в `components/LICENSE.txt`.
Репозиторий: https://github.com/DavidHDev/react-bits.

Сохранены исходные поверхности Prompt Bar, цвет эффекта максимального effort, частицы,
морфинг SVG, волна по решётке, таймеры, дыхание и сворачивание этапов.
Адаптации: Tabler из зависимостей проекта, русские подписи, поиск кириллицы,
колбэк модели для условного effort, клавиатурный фокус, исправление закрытия меню по первому
клику. Подсветка строки меню смещается через transform. Значение effort меняется сразу,
ползунок и заполнение плавно переходят за 220 мс через transform; быстрое переключение
прерывает текущий переход. Подпись проявляется за 160 мс. В reduced motion перемещение
и проявление подписи отключены.
Системный reduced motion и переключатель демо останавливают частицы и морфинг,
упрощают переходы этапов, смягчают волну.
