## 🎯 Актуальность

Несмотря на стремительное развитие генеративного ИИ, создание презентаций в фирменном стиле компании по-прежнему требует участия дизайнеров и ручной адаптации шаблонов.

Существующие AI-инструменты хорошо генерируют содержание, но значительно хуже справляются с задачей по воспроизведению **структуры, визуальных паттернов и дизайна**. Для этого нужно:

- разобрать шаблон и выделить дизайн-систему;
- понять логику использования разных типов слайдов;
- подобрать подходящий паттерн под новый контент;
- автоматически сверстать результат.

Решение этой задачи позволит автоматизировать один из самых массовых бизнес-процессов — подготовку презентационных материалов, сократив время их создания с часов до минут и обеспечив единый стандарт оформления независимо от автора документа.

Этот кейс проверяет не качество промптов, а способность участников строить **полноценный AI-пайплайн**: парсинг документов, извлечение структуры, компьютерное зрение, LLM-оркестрация и многое другое.

&nbsp;
## 🧩 Описание задачи

Разработайте сервис, который включает:

- **Навык**, способный анализировать презентационные шаблоны, извлекать их структуру, дизайн-систему и типовые паттерны слайдов;
- Автоматическое создание новой презентации на основе предоставленного контента.

Решение должно демонстрировать способность **адаптироваться к разным стилям оформления** и генерировать готовый результат **без ручного редактирования**.

&nbsp;
## 📦 Ресурсы

- Inference API для доступа к LLM;
- 3 шаблона презентаций различных стилей (предоставляются организаторами);
- 1 набор контента (текст, данные и описание продукта);
- CLI для разработки и интеграции.

&nbsp;
## 🚀 Описание итогового продукта

Open-source решение, обеспечивающее автоматическое создание презентаций в стиле произвольного шаблона. Результат должен подтверждать, что система **адаптируется к стилю шаблона**, а не работает по заранее зашитым сценариям.
