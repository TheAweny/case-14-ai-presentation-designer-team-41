# Проверка интеграции содержания — 2026-10-19

База: `ac8a7de`. Ветка: `theaweny/content-quality-variants`.
Все проверки выполнялись без обращений к моделям и без изменения production.

## Реализовано

- Один общий planner; новый план явно возвращает обязательные утверждения с цитатами.
  Подтверждённые пункты пользовательского outline заменяют модельные claims. Model outline
  не получает статуса approvedSlide и не подтверждает собственные факты.
- По умолчанию independent: отдельные writer jobs `(slide, variant)`. Явный shared оставляет
  один balanced writer на слайд. Политика фиксируется в immutable spec, manifest и задачах.
  Отсутствующее поле старого spec означает shared; несовместимые зависимости не переиспользуются.
- Передаются группы, semanticRole/groupId, метрики геометрии и безопасная вместимость.
  Перенос по heading/body сохраняет группы и порядок процесса; равенство числа слотов
  недостаточно. Неоднозначный старый индекс сохраняет исходную композицию.
- Writer собирается из общего файла, одного audience module, одного density module и
  text/native/QR output module. Модули входят в хеш агента manifest и registryHash spec.
  Версии: planner 2.10.0, writer 3.0.0, critic 1.11.0, rewriter 1.9.0.
- Калибруемые диапазоны плотности отделены от безопасного потолка. Измеренная capacity
  используется при наличии; sample-защита старых профилей сохранена. Подписи не растягиваются
  по правилам больших body. Общие знания не разрешают выдумать свойства продукта.
- Ремонт адресный, один семантический запрос за вызов, с общим attempt budget. Сохранены
  три альтернативы; выбор учитывает цель варианта и защиту деталей обязательных утверждений.
  Неудачные альтернативы не заменяют прежний текст механическим обрезанием.
- Критик читает итоговые тексты и отношения групп. Checkpoints учитывают текст, связи,
  источники, инструкции и выходную схему. Покрытие проверяется отдельно для каждого варианта.
- Mastra, лимитер, Retry-After, deadlines, ownership/fencing, отмена и публикация сохранены.
  Глобальные thinking/sampling, зависимости Mastra, сервер чата и интерфейс не менялись.

## Переключение

Добавить в существующий JSON `POST /generation`:

```json
{ "variantCopyMode": "independent" }
```

Это значение по умолчанию. Для экономичного пути использовать `"variantCopyMode":"shared"`.
При смене политики создать новый requestId/build. Resume использует сохранённую политику;
не нужно редактировать spec или переносить checkpoints вручную. После смены registry/schema
старые сборки могут честно отклонить resume из-за несовпадения immutable dependencies.

## Ограничения и интеграция 2/3

- Исполнитель 2: Zod и сгенерированное `CompositionSlot.capacity={safeChars,basis}` готовы;
  TS потребляет поля. Python-алгоритм расчёта метрики здесь не изменялся и от коллеги не
  поступил. На профилях без capacity остаётся прежняя защита по sample. Перенос реального
  текста по шрифтовым метрикам остаётся ответственностью движка.
- Исполнитель 3: подготовленные audience/goal и факты передаются существующими outline/brief.
  Новая политика вопросов/подготовки чата здесь не реализовывалась; соответствующие файлы
  не менялись. Контракт стыковки — [integration-contract.md](integration-contract.md).
- Строковые guards деталей консервативны и не доказывают логическое следование. Семантическая
  корректность остаётся задачей критика; fake recordings проверяют контракт и обработку его
  ответов, а не качество реальной модели. При отсутствии данных одинаковые короткие тексты
  разрешены; диапазоны длины требуют дальнейшей калибровки на реальных шаблонах.
- Несовместимый макет не получает факты от другого блока; исходная композиция сохраняется.
  Неразрешённое переполнение возвращается существующим content-overflow/quality путём.
  Факты не удаляются ради помещаемости и не прячутся только в заметки.
- Живые VK-запросы, реальный export/render, нагрузочный замер и browser-прогон этой версии
  не выполнялись. Deadline 290 секунд и включение render в него сохранены и проверены
  офлайн. Скорость fake provider не является скоростью VK и не доказывает SLA 5 минут.
