# Карта переноса

Первый источник — незакоммиченный ранее портал внутри `apps/web`, сохранённый в ветке `theaweny/docs-portal-foundation` (`apps/web/content/docs/*.md`). В `main` этих файлов нет.

Руководства нового CLI перенесены из `docs/cli/` и `docs/INSTALLATION.md` после сверки с
новой реализацией установщика. Канонические статьи теперь находятся в `content/docs/cli/`:
обзор, установка, настройки, сервисы, пользователи, обслуживание и генерация. Снимки терминала —
в `public/images/cli/`, у каждого есть alt и подпись с контекстом демонстрационных данных.
Страницы явно отмечают, что новая реализация CLI пока не объединена с `main`.

| -------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------ |

## Следующий этап наполнения

После ближайших изменений продукта:

- скриншоты веб-интерфейса в `public/images/<раздел>/` (снимки CLI уже добавлены);
- пошаговая первая презентация;
- материалы, живой аудит, диалог экспорта;
- руководство по квотам;
- как устроены агенты в `registry/agents` и как поднимать версию промпта;
- кодогенерация контрактов и добавление проверки аудита;
- примеры интеграции API без секретов;
- маршруты `/speech`, когда у контроллера появятся декораторы OpenAPI;
- отдельные заметки «симптом → проверка → действие» по генерации, шаблонам и редактору;
- английский перевод и только затем переключатель языка.
