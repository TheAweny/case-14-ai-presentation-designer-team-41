Страница показывает компоненты, которыми пишутся статьи. Текст вокруг них — про сам портал, не про продукт.

## Примечания

<Info>Информация: нейтральное уточнение, без которого абзац читается неполно.</Info>

<Tip>Совет: как удобнее сделать то, что и так возможно.</Tip>

<Warning>Предупреждение: легко ошибиться, если пропустить этот абзац.</Warning>

<Limitation>Ограничение: так сделать нельзя, и обходной путь в эту заметку не входит.</Limitation>

## Шаги

<Steps>
  <Step>Создайте файл в `content/docs`.</Step>
  <Step>Добавьте его имя в `meta.json`.</Step>
  <Step>Поставьте ссылку из соседней статьи и прогоните `yarn nx run docs:test`.</Step>
</Steps>

## Вкладки

<Tabs items={['macOS', 'Linux']}>
  <Tab>На macOS портал тоже статический: отдайте каталог `apps/docs/out`.</Tab>
  <Tab>На Linux тот же каталог кладётся в корень сайта, например nginx.</Tab>
</Tabs>

## Код

Блок ниже с названием файла. Кнопка копирования — часть темы Fumadocs.

```bash title="apps/docs/serve.sh"
yarn nx run docs:serve
```

## Таблица

| Компонент    | Зачем                                        |
| ------------ | -------------------------------------------- |
| `Info`       | Уточнение                                    |
| `Tip`        | Совет                                        |
| `Warning`    | Риск ошибки                                  |
| `Limitation` | Жёсткая граница                              |
| `ReviewNote` | Статья перенесена и не перепроверена целиком |
| `MediaSlot`  | Рамка под будущий снимок или видео            |

## Рамка под запись

`<MediaSlot kind="video" title="Что будет на записи." />` или `kind="image"`. Рамка не ссылается на файл. Когда запись появится, её кладут в `public/images/<раздел>/` и заменяют рамку на `<Figure>`.
