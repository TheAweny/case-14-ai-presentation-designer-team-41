Схема каждой заметки: симптом, что проверить, что сделать. Здесь только то, что следует из кода доступа и `lct doctor`. Отдельные страницы про генерацию, шаблоны и редактор будут позже.

## 401, сессия завершена

**Симптом.** API отвечает 401, в тексте — войти снова.

**Проверка.** Запрос к маршруту аккаунта ушёл с `x-lct-user`, но без подходящего `x-lct-session`, либо сессию отозвали.

**Действие.** Войти в приложение заново. Не подставлять чужой id. Подробности — в [доступе](/docs/api/access/).

## 403, API отвечает только веб-серверу

**Симптом.** 403 с формулировкой, что API отвечает только веб-серверу этой установки.

**Проверка.** Вызов идёт прямо на порт API и в нём нет `x-lct-service-token`, либо токен короче 32 символов и процесс его не принял.

**Действие.** Ходить через приложение. Токен лежит в `.env` как `API_SERVICE_TOKEN` и в документацию не копируется. Если доктор пишет, что секрет пустой или взят из примера, запустить `lct onboard`.

## Модель не отвечает

**Симптом.** `lct doctor` останавливается на проверке модели.

**Проверка.** В `.env` заполнены `MODEL_PROVIDER`, `LLM_BASE_URL`, `LLM_MODEL` и ключ. Доктор печатает деталь ответа, не сам ключ.

**Действие.** Поправить адрес и модель. Ключ в чат и в тикет не вставлять.

## Веб или API не открываются

**Симптом.** Страница входа или `http://localhost:3001/health` не отвечают.

**Проверка.** `lct status`. Доктор отдельно пишет, запущены ли веб (`http://localhost:3000`) и API (`http://localhost:3001/health`).

**Действие.** `lct start`. Логи одного сервиса: `lct logs api` или `lct logs web`.

## На сайте документации не работает `/api/backend`

**Симптом.** Запрос к относительному `/api/backend` с поддомена документации падает.

**Проверка.** Хост — портал, а не приложение.

**Действие.** Этот путь есть только у веб-приложения. Документация его не проксирует. Открыть приложение ссылкой из шапки.

<Tip>
  Новую заметку добавляйте в этот же формат и только после того, как симптом нашёлся в коде или в
  `lct doctor`. Не копируйте сюда отчёты из `docs/`.
</Tip>
