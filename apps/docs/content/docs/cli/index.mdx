`lct` устанавливает дизайнер презентаций на Ubuntu, подключает модель и помогает обслуживать
приложение через SSH. После установки достаточно выполнить `lct`: откроется меню с адресом
приложения и состоянием сервисов.

Для другой установки можно явно задать каталог: `LCT_HOME=/opt/lct26 lct status`.

## Навигация в терминале

В меню используйте ↑ и ↓ для выбора, Enter для подтверждения. Длинные списки прокручиваются:
многоточие внизу означает, что дальше есть другие действия. Ctrl+C отменяет текущий ввод;
при отмене вложенного действия главное меню остаётся доступным. Для завершения работы выберите
«Выход» или отмените ввод в самом главном меню.

Главное меню показывает, запущены ли контейнеры `api`, `web`, `engine`, `postgres`. Проверить
ответы HTTP и подключение к модели можно через `lct doctor`: индикатор состояния контейнеров
сам по себе не подтверждает работоспособность всех функций приложения.

## Оформление и прогресс

Заставка, заголовки и полосы используют плавное нейтральное переливание: серый, светло-серый,
мягкий белый. Полосы подстраиваются под ширину терминала, в том числе при подключении с телефона.

При скачивании процент появляется только при известном размере файла. Сборка контейнеров,
проверка модели и ожидание запуска показывают движение без процента.

```bash title="terminal.sh"
# Оставить оттенки, отключить движение.
LCT_REDUCED_MOTION=1 lct

# Простой вывод и вопросы без ANSI-оформления.
NO_COLOR=1 lct

# Справка со всеми основными командами.
lct help
```

Без TTY команда `lct` печатает справку. Команды, которым нужны ответы, требуют параметров
или окружения shell; для мастера установки дополнительно нужен `--yes`.

## Об иллюстрациях

Снимки получены из настоящего вывода CLI и Bash-установщика на демонстрационных данных.
Docker, API аккаунтов и проверки доступности заменены локальными адаптерами. При съёмке
сервис не устанавливался и не изменялся. Домен и почта приведены для примера;
процент загрузки задан сценарием. Каждая иллюстрация фиксирует один кадр переливания.
