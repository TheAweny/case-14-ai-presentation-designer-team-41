Страница `/admin` открывается администратору. У остальных её нет: ни в меню, ни по прямому адресу. Обычный пользователь свои проекты видит, чужие — нет, и завести аккаунт сам не может.

## Обзор

Счётчики аккаунтов, администраторов и отключённых. Карточки ведут в соседние разделы.

## Люди

Список с поиском и фильтрами по роли и доступу.

| Действие | Что делает |
| --- | --- |
| Добавить | Новый аккаунт: почта, имя, пароль, роль |
| Сделать администратором / пользователем | Меняет роль |
| Отключить / Включить | Блокирует вход или возвращает его |
| Удалить | Удаляет аккаунт |
| Сбросить пароль | Выдаёт новый пароль один раз, чтобы его передать |
| Завершить сессии | Отзывает входы этого человека |
| Лимиты | Открывает личный лимит |

Пароль нового аккаунта — от 8 до 200 символов. Роли две: пользователь и администратор.

Те же действия есть у CLI: [пользователи](/docs/cli/users/) и [команды одной строкой](/docs/cli/reference/).

## Настройки лимитов

Раздел называется «Настройки». Общая политика действует на всех. Личный лимит заменяет её только у выбранного аккаунта. «Как у всех» возвращает к общей политике.

Метрики, у которых есть предел:

| Метрика | Смысл |
| --- | --- |
| Успешные генерации | Три варианта одной колоды считаются одной генерацией |
| Ответы ассистента | Каждый законченный ответ |
| Сохранённые редакции | Правки, записанные редактором |
| Параллельные сборки | Сколько сборок может идти одновременно |
| Хранение | Место презентаций и файлов |

«Самостоятельные изображения» в показателях есть, но отдельная генерация картинок вне колоды пока недоступна. Картинки внутри колоды в этот счётчик не входят.

У политики есть период и часовой пояс. Сохранение записывает значения. «Отозвать все сессии» завершает входы выбранного аккаунта. Ссылка «Модели» открывает настройки моделей.

## Показатели

Таблица расхода по аккаунтам: поиск, сортировка по месту или по имени, обновление. Прочерк значит, что данных нет, они неполные или периоды счётчиков нельзя сложить. Хранение — текущий объём, а не расход за период. Строка «Лимиты и сессии» открывает личный лимит.
