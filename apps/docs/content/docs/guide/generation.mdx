---
title: Генерация
description: Что делает сборка колоды, какие этапы видны и как пересобрать один вариант.
---

Сборку запускает агент, когда режим это позволяет и есть шаблон. В интерфейсе человек не выбирает один из трёх вариантов заранее: сервер строит один план и раскладывает его в три вёрстки.

## Этапы

Карточка хода называет этапы так:

| Этап | Подпись |
| --- | --- |
| `queued` | Очередь |
| `parsing-template` | Разбор шаблона |
| `profiling-template` | Профиль шаблона |
| `planning` | План колоды |
| `illustrating` | Иллюстрации |
| `laying-out` | Вёрстка вариантов |
| `rendering` | Превью |
| `auditing` | Аудит |
| `exporting` | Сборка файлов |

Очередь появляется, когда сервер её сообщил. Профиль шаблона для уже разобранного файла берётся из памяти и заново не считается. Карточка показывает, сколько времени прошло и какой запас ещё есть. У прогона есть срок: вариант останавливается, когда срок вышел.

Если провайдер модели ответил 429, сборка останавливается, план сохраняется. Повтор — позже или с другой моделью.

## Что получается

Готовая карточка называется «Три варианта вёрстки». Подписи: **Плотный**, **Сбалансированный**, **Воздушный**. Совет, какой открыть, считается по аудиту сборки: сначала меньше ошибок, затем меньше замечаний, при равенстве — сбалансированный. Проверки открытого редактора в этот счёт не входят.

У варианта есть открытие, показ, скачивание и переход в редактор. Если один вариант не собрался, остальные остаются. Кнопка «Пересобрать» запускает его заново по тому же плану.

## Остановка и продолжение

Ответ ассистента можно остановить. Сборку, которая уже пошла, сервер умеет отменить и продолжить: у прогона есть отдельные действия отмены и возобновления. Застрявшую подготовку сервер подбирает сам.

Демо-подстановка, если она включена на сервере, колоду выбранным шаблоном не верстает. Карточка прямо пишет, что варианты взяты из готовых демо-колод.

Сборка одной командой, без этого чата, описана в [генерации CLI](/docs/cli/generation/).
