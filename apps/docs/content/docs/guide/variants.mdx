---
title: Три варианта
description: Общий план и три имени вёрстки. Таблица плотности требует повторной сверки.
---

<ReviewNote />

Одна сборка отдаёт три колоды с именами `dense`, `balanced` и `airy`. План общий: порядок слайдов и факты не разъезжаются между вариантами.

В коде генерации рабочий способ выбора макета называется `density`. Комментарий к типам говорит, что варианты отличаются композицией и плотностью, а не фактами (`packages/pipeline/src/generation/workflow.ts`). Рядом есть экспериментальные политики `preserve-block-count` и `conceptual`; в обычной сборке они не включаются.

Таблица ниже перенесена из черновика и описывает только ось плотности. Её не стоит считать окончательным описанием карточки результата, пока вёрстка не стабилизируется.

| Вариант    | Что меняется по черновику                                             |
| ---------- | --------------------------------------------------------------------- |
| `dense`    | самые заполненные макеты, меньший кегль, длинный список в две колонки |
| `balanced` | средние макеты и основной кегль                                       |
| `airy`     | просторные макеты и самый крупный кегль, в который текст ещё влезает  |

Карточка результата сама называет вариант. Сначала меньше ошибок аудита сборки, потом меньше замечаний, при равенстве — сбалансированный. Это числа сборки. Живой аудит открытого редактора в подсчёт не входит: у него другой набор проверок.

Подробнее о том, как план становится SlideIR, — в [пайплайне](/docs/internals/pipeline/).
