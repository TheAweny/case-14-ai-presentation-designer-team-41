Окно настроек открывается с любой страницы библиотеки и из редактора. Адрес получает параметр `?settings=`. Старый адрес `?settings=users` у администратора ведёт на [панель администрирования](/docs/guide/admin/), а не в это окно.

## Разделы

| Раздел | Что внутри |
| --- | --- |
| Аккаунт | Аватар, смена пароля, расход и лимиты только для чтения, выход на этом устройстве |
| Общие | Язык интерфейса |
| Редактор | Панель инструментов, панель над объектом, холст, привязка, колесо мыши |
| Клавиши | Справка сочетаний |
| Презентации | Число слайдов по умолчанию, формат и имя экспорта |
| Модели | Подключения, проверка, роли сборки, включённые модели |

Имя и почту человек сам не меняет: это делает администратор. Пароль меняется здесь. Новый пароль — от 8 до 200 символов.

Аватар — один из знаков или своё фото: PNG, JPEG, WebP или HEIC, до 20 МБ. Фото обрезается в квадрат.

## Редактор

Настройки редактора применяются сразу, в том числе к уже открытой колоде.

Панель инструментов можно ужать: графики и таблицы, ассистент, справка клавиш, показ. «Оставаться в инструменте после вставки» оставляет фигуру выбранной, чтобы поставить несколько подряд.

Панель над объектом бывает у объекта, над холстом или скрыта. Скрытая панель оставляет свойства во вкладке «Дизайн».

## Презентации

Число слайдов по умолчанию — **Авто** или число от 5 до 15. «Авто» отдаёт длину планировщику. Именованное число уходит в запрос.

Рядом выбираются формат экспорта и шаблон имени файла.

## Модели

Подключение — адрес OpenAI-совместимого API, ключ и заголовки, которые просит провайдер. Ключ хранится зашифрованным. В ответах интерфейса виден признак «ключ есть» и хвост ключа, не сам ключ.

Роли сборки:

| Роль | Подпись | Обязательна |
| --- | --- | --- |
| `assistant` | Ассистент | да |
| `planner` | Планировщик | да |
| `writer` | Автор текстов | да |
| `critic` | Критик | да |
| `vision` | Визуальная проверка | да |
| `image` | Иллюстратор | нет |
| `speech` | Расшифровка голоса | нет |

Без назначения речи берётся первая голосовая модель из подключений. Пункт «Без расшифровки голоса» убирает кнопку микрофона.

Проверка подключения спрашивает список моделей у провайдера. Выключенная модель в поле запроса помечается недоступной.

Флаг **«Общее»** у подключения есть только у администратора: такое подключение видят остальные аккаунты.
