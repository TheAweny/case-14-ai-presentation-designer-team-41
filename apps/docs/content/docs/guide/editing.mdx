title: Правка и экспорт
description: Живой аудит в редакторе и экспорт открытого слайда.

<ReviewNote />

Проверки в редакторе идут после каждой правки, как линтер: переполнение, наложение, выход за поля, контраст, заглушки. «Исправить» только сдвигает объект в свободное место внутри полей шаблона. Сократить текст или сменить макет проверка не берётся — это делает агент, и ту же проверку проходит его правка.

Экспорт пишет файл из того слайда, который виден: `.pptx`, `.pdf`, PNG и HTML.

Картинка слайда готовится один раз и попадает во все три варианта. Слот, для которого картинки нет, со слайда убирается: пустая рамка выглядит как незаконченная работа.
