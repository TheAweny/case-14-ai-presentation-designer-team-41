---
title: Инструменты агента
description: Что ассистент может вызвать сам, пока отвечает в чате.
---

Инструменты — действия сервера, которые ассистент вызывает по ходу ответа. Человек их не нажимает по одному. В ленте чата видно, какой инструмент шёл и чем кончился. Часть инструментов в режиме «Чат» скрыта: собрать колоду там нельзя.

Ниже — имена, которыми инструмент называется в коде. Описание взято из того, что сервер реально подключает к ассистенту.

## Спросить и запомнить

| Инструмент | Зачем |
| --- | --- |
| `ask_user` | Один вопрос с вариантами ответа. Ход на этом останавливается. Есть в «Плане» и «Авто». |
| `save_preparation` | Запоминает подготовку: аудиторию, цель и соседние поля. |
| `propose_plan` | Карточка плана колоды. Есть в «Плане» и «Авто». |
| `build_deck` | Сборка трёх вариантов по плану и шаблону. Есть в «Плане» и «Авто». |
| `read_build_status` | Состояние сборки в этом чате. |

## Шаблон и материалы

| Инструмент | Зачем |
| --- | --- |
| `list_templates` | Шаблоны библиотеки, до сорока. |
| `describe_template` | Имя, цвета и макеты шаблона. |
| `inspect_template_layout` | Слоты одного макета. |
| `read_file` | Текст вложения постранично. |
| `extract_material` | Подготовленный текст вложения. |
| `read_table` | Строки таблицы из CSV, TSV или XLSX. |
| `search_materials` | Поиск по приложенному файлу. Появляется, когда файл есть. |
| `research_materials` | Вопрос к вложениям через субагента [material-researcher](/docs/guide/agents/). |
| `calculate` | Арифметика по числам, которые уже есть в разговоре. |

## Веб

Поиск включается установкой. Без него `search_web`, `research_topic` и `search_assets` агенту не выдаются. В CLI это флаги `--search` и `--no-search`.

| Инструмент | Зачем |
| --- | --- |
| `search_web` | Поиск. Сниппеты поиска сами по себе не считаются фактами для слайда. |
| `fetch_source` | Загрузка публичной страницы по адресу. |
| `research_topic` | Исследование темы через субагента [web-researcher](/docs/guide/agents/). |
| `search_assets` | Подбор иллюстраций. |
| `inspect_sources` | Откуда в чате взяты уже загруженные источники. |
| `generate_qr` | PNG с QR-кодом точного адреса. |

## Уже собранная колода

| Инструмент | Зачем |
| --- | --- |
| `read_deck` | Тексты слайдов колоды этого чата. |
| `read_audit` | Ошибки и замечания аудита сборки. |
| `preview_slide` | PNG одного сохранённого слайда. |
| `check_slide_fit` | Влезает ли текст в слот. |
| `check_content_coverage` | Покрывает ли текст слайда факты плана. |
| `edit_slide` | Новый текст объекта, который прикрепили из редактора. Правка попадает в черновик, её можно отменить. |

<Limitation>
  Инструмент не появляется в режиме, для которого он выключен. «Чат» не предлагает план, вопрос с вариантами и сборку.
</Limitation>
