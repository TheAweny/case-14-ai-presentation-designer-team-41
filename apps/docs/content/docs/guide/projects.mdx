Вошедший человек видит библиотеку. Чужие проекты, шаблоны и чаты API не отдаёт.

## Куда ведёт меню

| Пункт | Куда |
| --- | --- |
| Новая презентация | Главная, поле запроса уже открыто |
| Проекты | Список проектов |
| Шаблоны | Библиотека шаблонов аккаунта |
| Администрирование | Только у администратора |

Слева же история чатов: строка открывает `/chats/…`. Карточка готовой колоды ведёт в чат, если у неё есть чат, и в редактор, если чата нет.

## Проект

Проект — папка колод, чатов и шаблонов. Создаётся диалогом «Новый проект»: название, значок и цвет.

На странице проекта две вкладки: **Презентации** и **Шаблоны**. Шаблон к проекту прикрепляют и открепляют. Пока шаблонов нет, страница предлагает прикрепить файл.

У объекта в библиотеке есть меню: открыть, показ, переименовать, перенести в проект, удалить.

## Шаблон

Шаблон — файл `.pptx` или `.potx`. Пустой файл и файл другого типа не принимаются. Имя файла ни на что не влияет: незнакомый шаблон разбирается так же, как свой. Разбор читает палитру, шкалу кеглей, сетку и макеты.

Шаблоны живут в библиотеке `/templates`: загрузка, переименование, удаление, скачивание оригинала. Значок «Общий» есть у шаблона, который администратор открыл всем. Обычный пользователь общий шаблон не создаёт.

В поле запроса шаблон выбирают из проекта, из библиотеки или загружают новым файлом.

## Материалы

К запросу прикрепляются непустые файлы:

| Расширение | Чем становится |
| --- | --- |
| `.txt`, `.md`, `.docx`, `.pdf` | текст |
| `.csv`, `.tsv`, `.xlsx` | таблица |

Картинка материалом не становится. `.pptx` и `.potx` в этом поле — всегда шаблон, а не текст.

Тот же файл второй раз не прикрепляется: его узнают по имени, размеру и времени правки.

## С чего начинается колода

Поле запроса стоит на главной и внутри проекта. В нём текст задачи, вложения, шаблон, модель и режим. Число слайдов берётся из настроек «Презентации». Отправка создаёт чат и открывает его.
