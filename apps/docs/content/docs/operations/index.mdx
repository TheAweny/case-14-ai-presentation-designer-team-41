---
title: Установка и эксплуатация
description: Установка на чистую Ubuntu, управление приложением, диагностика и резервные копии.
---

Обычная установка начинается с чистой Ubuntu и SSH-доступа. Bash-установщик подготавливает
системные зависимости, затем CLI подключает модель, создаёт администратора и запускает приложение.

<Steps>
  <Step>
    [Установите приложение на Ubuntu](/docs/cli/installation/): одна команда, мастер настройки и
    первый вход.
  </Step>
  <Step>
    [Настройте модель и доступ](/docs/cli/configuration/): IP или домен с HTTPS, порты и
    возможности.
  </Step>
  <Step>[Создайте пользователей](/docs/cli/users/) и передайте им адрес приложения.</Step>
</Steps>

## Обслуживание

| Задача                                | Руководство                                   |
| ------------------------------------- | --------------------------------------------- |
| Запуск, остановка, логи и диагностика | [Управление сервисом](/docs/cli/service/)     |
| Резервная копия и обновление          | [Копии и обновления](/docs/cli/maintenance/)  |
| Генерация без браузера                | [Генерация по конфигу](/docs/cli/generation/) |
| Сессии и запросы к API                | [Доступ к API](/docs/api/access/)             |

<Info>
  Портал открывается отдельно от приложения. Пробные запросы к API включаются на сервере
  переменной `API_DOCS_ENABLED` и описаны в [консоли](/docs/api/console/).
</Info>

## Аккаунты и квоты

Ограничения аккаунта необязательны и управляются администратором приложения. Контракты
доступны в [справочнике пользователей](/docs/api/reference/users/).
