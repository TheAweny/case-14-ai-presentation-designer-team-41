Портал документации не импортирует пакеты продукта и не требует PostgreSQL, движка и моделей. Этот раздел — карта репозитория, а не второе приложение.

## Локально

- Node.js 22.13+, Python 3.12.
- Зависимости TypeScript — `yarn`, Python — `uv`. npm и pip для этого репозитория не используются.
- Проверки — цели Nx: `yarn nx run <project>:lint`, `typecheck`, `test`, `build`.
- Портал: `yarn nx run docs:serve` (порт 3002) и `yarn nx run docs:build`. Перед сборкой Nx снимает OpenAPI целью `api:export-openapi`. База для этого не нужна: сервисы в тестовом модуле заменены заглушками.

Поднять сам продукт — [установка](/docs/operations/) и [CLI](/docs/cli/).

## Куда смотреть

| Вопрос           | Где                                                                   |
| ---------------- | --------------------------------------------------------------------- |
| Границы слоёв    | [Слои](/docs/internals/layers/)                                       |
| Контракты        | [Контракты](/docs/developers/contracts/) и `packages/contracts`       |
| Агенты и промпты | каталог `registry/agents/<id>/`, отдельными файлами, с версией semver |
| Пайплайн         | `packages/pipeline`                                                   |
| Движок           | `engine/`, слои не импортируют друг друга                             |
| Тесты без сети   | фейковый провайдер моделей и записанные ответы                        |

Промптов в коде TypeScript быть не должно: их читает загрузчик реестра. Как добавить агента и поднять версию, будет отдельная статья. Менять смысл инструкции без смены версии нельзя.
