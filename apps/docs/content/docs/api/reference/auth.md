Проверка пароля для веб-сервера, который держит сессию.

## `GET /auth/accounts`
**Есть ли аккаунты**
Пустая установка: страница входа предлагает создать администратора.
### Ответы

| Код | Описание | Схема |
| --- | --- | --- |
| 200 | Успешно. | object |
| 403 | Нет прав: запрос не от веб-сервера или действие только для администратора. | [ApiError](/docs/api/reference/schemas/#ApiError) |

## `GET /auth/accounts/{id}`
**Аккаунт по id**
Веб-сервер проверяет сессию на каждой странице. Отключённый — `null`.
### Параметры

| Имя | Где | Обязателен | Описание |
| --- | --- | --- | --- |
| `id` | path | да | id аккаунта из сессии. |
| `x-lct-session` | header | да |  |

### Ответы

| Код | Описание | Схема |
| --- | --- | --- |
| 200 | Успешно. | object |
| 403 | Нет прав: запрос не от веб-сервера или действие только для администратора. | [ApiError](/docs/api/reference/schemas/#ApiError) |

## `POST /auth/logout`
**Отозвать текущую сессию**
### Параметры

| Имя | Где | Обязателен | Описание |
| --- | --- | --- | --- |
| `x-lct-session` | header | да |  |

### Ответы

| Код | Описание | Схема |
| --- | --- | --- |
| 204 | Готово, тела нет. | — |
| 403 | Нет прав: запрос не от веб-сервера или действие только для администратора. | [ApiError](/docs/api/reference/schemas/#ApiError) |

## `POST /auth/verify`
**Проверить почту и пароль**
Неверный пароль, неизвестная почта и отключённый аккаунт отвечают `{ "account": null }`.
### Тело запроса

- `application/json` — [Credentials](/docs/api/reference/schemas/#Credentials)

### Ответы

| Код | Описание | Схема |
| --- | --- | --- |
| 200 | Успешно. | object |
| 400 | Неверный запрос: тело или параметры не прошли проверку. | [ApiError](/docs/api/reference/schemas/#ApiError) |
| 403 | Нет прав: запрос не от веб-сервера или действие только для администратора. | [ApiError](/docs/api/reference/schemas/#ApiError) |
| 429 | Слишком много попыток. Повторите запрос позже. | [ApiError](/docs/api/reference/schemas/#ApiError) |
