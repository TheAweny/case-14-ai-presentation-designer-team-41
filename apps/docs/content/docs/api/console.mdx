---
title: Консоль
description: Swagger по снимку OpenAPI. Запросы уходят в приложение от аккаунта, под которым вошли в шапке.
---

Консоль — тот же приём, что у Swagger: открыть операцию, нажать **Try it out**, заполнить поля и **Execute**. Снимок схемы собран вместе с сайтом, поэтому список маршрутов читается и при выключенном API. Отправка запроса уже требует живое приложение.

<MediaSlot kind="video" title="Кнопка «Войти» открывает приложение и возвращает сессию, затем в оглавлении консоли выбирается маршрут." src="/images/guide/console.gif" />

Кнопка **Войти** стоит внизу боковой панели, а на главной — в шапке. Она не спрашивает пароль здесь: открывает приложение и забирает сессию, которая там уже есть. Если в приложении входа нет, сначала показывается его страница входа, и после неё сессия возвращается на эту вкладку. Слева у консоли — оглавление операций. Справа операция раскрывается, **Try it out** и **Execute** отправляют запрос от этого аккаунта.

Сервер приложения добавляет служебный токен сам. Вводить `x-lct-service-token`, `x-lct-user` и `x-lct-session` не нужно: этих полей в консоли нет.

<Info>
  Консоль на сервере выключена, пока `API_DOCS_ENABLED` не равно `true`. Это тот же переключатель, что «Документация API» в `lct configure` и флаг `--docs`. На чужом адресе документации сервер ещё смотрит `DOCS_PUBLIC_URL`: туда записывают происхождение сайта документации, например `https://docs.example.com`. Адреса `http://localhost:3002` и `http://127.0.0.1:3002` разрешены и без этой переменной.
</Info>

Запрос идёт на адрес приложения из сборки документации (`NEXT_PUBLIC_APP_URL`), по пути `/api/docs-playground/…`. Ответ — ответ API для этого аккаунта. Маршрут администратора обычному пользователю вернёт 403. Маршруты диктовки `/speech` в снимок не входят: у контроллера нет описания OpenAPI.
