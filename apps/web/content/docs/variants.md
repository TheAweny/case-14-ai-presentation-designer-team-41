Одна сборка отдаёт три колоды. Слова, порядок слайдов и факты у них одни. Отличается плотность: так сравнивают вёрстку, а не содержание.

| Вариант    | Что меняется                                                          |
| ---------- | --------------------------------------------------------------------- |
| `dense`    | самые заполненные макеты, меньший кегль, длинный список в две колонки |
| `balanced` | средние макеты и основной кегль                                       |
| `airy`     | просторные макеты и самый крупный кегль, в который текст ещё влезает  |

Карточка результата сама называет вариант. Сначала меньше ошибок аудита сборки, потом меньше замечаний, при равенстве — сбалансированный. Это числа сборки. Живой аудит открытого редактора в подсчёт не входит: у него другой набор проверок.
