Сервис собирает презентацию по загруженному шаблону `.pptx` и материалам. План колоды пишется один раз, вёрстка раскладывает его в три варианта плотности.

```text
шаблон .pptx ─► разбор ─► профиль шаблона ─┐
                                           ├─► вёрстка ─► SlideIR ─► аудит ─► экспорт
материалы ────► план колоды (один раз) ────┘
```

Разбор читает из файла палитру, шкалу кеглей, сетку и макеты. Если текст не влезает, вёрстка его не переписывает: она возвращает сигнал переполнения, а новый текст пишет агент. Маршруты запуска — в [генерации](/api/docs/reference/generation).

## Три плотности

Порядок слайдов и формулировки у всех трёх вариантов одинаковые. Отличается плотность. Модель не выдаёт координаты: размеры берутся из шкалы шаблона, колонки — из его сетки.

| Вариант    | Макеты               | Кегль                                       | Внутри слота                              |
| ---------- | -------------------- | ------------------------------------------- | ----------------------------------------- |
| `dense`    | самые заполненные    | меньшая ступень текста                      | длинный список делится на две колонки     |
| `balanced` | средние по плотности | ступень основного текста                    | как задумано макетом                      |
| `airy`     | самые просторные     | крупнейшая ступень, в которую текст влезает | короткий текст выравнивается по вертикали |
