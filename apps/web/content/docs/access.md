Браузер не ходит в API напрямую. Страницы вызывают `/api/backend/…` и передают cookie сессии. Веб-сервер добавляет два заголовка:

- `x-lct-service-token` — общий секрет веб-сервера и API. Браузер его не видит.
- `x-lct-user` — id вошедшего аккаунта, взятый из сессии.

Без токена открыт только `GET /health`. Маршруты, которые прокси браузеру не отдаёт, в справочнике помечены: их вызывает сам веб-сервер.

Чтобы отправить запрос со страницы маршрута, войдите. «Try it out» пойдёт с вашей сессией.

## Ошибки

| Код | Когда                                                            |
| --- | ---------------------------------------------------------------- |
| 400 | Тело или параметры не прошли проверку.                           |
| 401 | Аккаунт не назван, удалён или отключён.                          |
| 403 | Запрос не от веб-сервера или действие только для администратора. |
| 404 | Объекта нет или он принадлежит другому аккаунту.                 |
| 409 | Действие сейчас невозможно.                                      |
| 422 | Движок не смог прочитать файл.                                   |
| 503 | Недоступен движок, база или хранилище ключей.                    |
| 504 | Движок не ответил вовремя.                                       |
