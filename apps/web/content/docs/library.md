Проект — папка для колод, чатов и шаблонов. Чужое в неё не попадает: API отдаёт только то, что принадлежит аккаунту.

Шаблон читается как профиль: палитра, шкала кеглей, сетка, макеты. От имени файла ничего не зависит, поэтому незнакомый шаблон идёт тем же путём, что и свой.

Карточка колоды в чате показывает готовые превью и не ждёт, пока движок заново разберёт файл. Если один вариант не открылся, остальные остаются. Полный слайд для редактора грузится отдельно, когда он нужен.
