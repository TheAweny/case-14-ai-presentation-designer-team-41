Схемы описываются один раз, в `packages/contracts`, на Zod. Модели Python собираются из них. Сгенерированные файлы вручную не правят: сборка сравнивает их с исходными схемами и падает на расхождении.

Запрос и ответ на границе TypeScript и Python проходят те же схемы. Имена на странице [схем](/api/docs/reference/schemas) — те же, что проверяют данные в коде.

У каждой схемы есть `schemaVersion`. Несовместимое изменение поднимает версию: старый пример перестаёт проходить проверку, пока новая версия не описана явно.
