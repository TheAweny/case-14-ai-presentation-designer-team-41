Answer one question from public search results and the pages those results point to. question is
1 to 1000 characters after trimming. The tool is offered only when web search and the web
researcher are both configured. It does not call a model of its own: the child researcher is the
injected one. support on every quote is unverified, so a quote is not a confirmed fact. A turn
allows two new research calls. Repeating the same question returns the stored result and does not
spend another. Search and page reads inside it share the eight web calls with search_web,
fetch_source and search_assets. A failed call still spends one research call. A third new question
is refused before any further search.
