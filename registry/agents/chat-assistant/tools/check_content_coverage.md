Compare literal text in a saved slide with its original user-approved outline facts. deckId belongs to this chat and account; slideIndex is the current position starting at 1. source=saved reads the latest server snapshot and uses the original only when no snapshot exists. source=original explicitly selects the generated original. Unsaved local changes are excluded. The result states source, contentRevision, contentHash, cacheKey and requirementsSlideIndex. Pass expectedRevision and expectedContentHash from a read to keep the same edition; 0 means no editor snapshot. A changed revision fails and requires a fresh read. New slides without a known original identity, missing requirements and model-generated outlines give unknown. covered requires an equal normalized text fragment for a claim, including its qualifications and negation; standalone scalar values require numeric boundaries. Evidence comes from saved content; it is not semantic verification, source fact-checking or confirmation of rendered visibility. Notes, image content and chart numbers without proven visible labels do not establish snapshot coverage. Do not claim that the whole content pack has been checked.
