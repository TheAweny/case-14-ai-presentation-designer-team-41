Read the published PNG preview of a saved slide. deckId must belong to this chat and account; slideIndex is its current position, starting at 1. By default source=saved reads the latest server editor snapshot, or the original only when the server confirms there is no saved snapshot. source=original explicitly selects the generated original. Unsaved local edits are never read. The result states source, contentRevision, contentHash and cacheKey. Pass expectedRevision and expectedContentHash from a previous read to inspect the same content; revision 0 means no editor snapshot. A changed revision fails and requires a fresh read. A snapshot preview is returned only from a published export with that exact revision and hash, otherwise status=not-rendered with no original PNG substituted. visionAssessment=false means the image has not been visually assessed; a URL alone is not evidence that you saw it.
